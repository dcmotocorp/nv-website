Project Title: PRISM 2.0 / 2.1 Client Portal Ticketing System
Client: Shoonya by Finvasia

Scope: Full-Stack Development (Frontend & Backend)

Project Overview:

Developed and delivered a comprehensive, secure ticketing module for the PRISM 2.0 and 2.1 Client Portals. The project involved end-to-end frontend and backend development, secure API integrations, and robust webhook implementations to handle complex user account operations, regulatory compliance requests, and payment processing.

Key Modules & Features Developed:

reKYC (Know Your Customer) Module:

Developed the reKYC ticketing scope with automated backend processing.

Integrated the CVL KRA Webhook to handle real-time data responses.

Engineered logic to process multiple automated status cases, including Modification Request Submitted, Modification Under Process, Modification Validated, Auto-Approved, Auto-Declined, and User Cancelled events.

DDPI (Demat Debit and Pledge Instruction) Activation System:

Developed the "Activate DDPI" ticketing flow.

Integrated Razorpay Payment Gateway to facilitate seamless payment processing for ticket initiation.

Successfully managed end-to-end sandbox testing and live production deployment for payment flows.

Account Management & Segment Activation:

Trading Account Reactivation: Built the backend flow for users to reactivate dormant trading accounts.

Demat Account Operations: Created ticket flows for old users to open new Demat accounts and generate DP IDs.

Segment Activation: Implemented options for users to enable specific exchange segments, including NSE Com and Mutual Fund segment toggles, dependent on strict KRA validation checks.

Core System Features:

Integrated secure PDF document upload functionality for user verification tickets.

Managed Merge Requests (MRs) and codebase version control on Finvasia’s internal Git environments (devtools.finvasia.com).
